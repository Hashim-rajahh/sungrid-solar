I added a service worker that saves all 16 app files on the phone, so SunGrid Solar opens and works with no signal (jobs, stock, quote calculator), plus an Offline page that tells an installer if the app is ready before a site visit. The difficult part was updating safely: a new version now waits until the user taps "Reload to update", so an installer in the middle of a quote never loses their work, and I checked this with 120 tests and a real Chromium run with the network switched off. Making the version number automatic (a hash of the files) and making a failed install never take over were the parts that took the most care.
